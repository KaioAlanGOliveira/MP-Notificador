# MJA2 — MP-Notificador

## Sobre o projeto

O **MeuNotificador** é um aplicativo Android desenvolvido com o objetivo de centralizar e facilitar a comunicação entre os integrantes de grupos de oração católicos. A aplicação é voltada à organização e à divulgação de avisos, notificações e mensagens religiosas, proporcionando acesso simplificado às informações relevantes para a comunidade.

O projeto prioriza a usabilidade, a organização das informações e a simplicidade da interface, buscando oferecer uma experiência de utilização intuitiva e alinhada ao contexto de comunidades católicas.

## Objetivos

- Centralizar informações e comunicados do grupo de oração.
- Facilitar o acesso a avisos e mensagens religiosas.
- Apoiar a comunicação entre os integrantes da comunidade.
- Proporcionar uma interface intuitiva e de fácil utilização.
